## 🇩🇪 Deutsch

> 🤖 Dieses Projekt wurde vollständig **vibecoded**, also mit Hilfe von KI erstellt – sowohl mit der **kostenlosen** als auch mit der **bezahlten** Version von Claude (Anthropic).

✅ Der Code ist **frei benutzbar**: Du darfst ihn verwenden, verändern und weitergeben.

▶️ **Starten:** Jede Datei ist eine einzelne `.html`-Datei. Einfach herunterladen und im Browser öffnen.

### 📂 Die Spiele & Seiten

| Datei | Beschreibung |
|---|---|
| 🕹️ **ASCII Arcade** | Fünf Retro-Spiele im ASCII-Look: **Doom, Pong, Tetris, Pacman** und **Nachtschicht**. Spiel mit den Pfeiltasten wählen, mit `Enter` starten. |
| ⛏️ **Klotzwelt** | Eigenes Voxel-Spiel im Minecraft-Stil mit Überleben- und Kreativmodus, Crafting, Monstern und Wetter. Texturen und Sounds werden live erzeugt. |
| 🎵 **Pulse Grid** | Rhythmusspiel: Mit dem Cursor die Noten im 3×3-Raster treffen. Eigene Songs laden (automatisch gemappt) oder `.sspm`/`.txt`-Maps importieren, dazu viele Mods. |
| 💉 **Overdose Protocol** | Rundenbasiertes Neon-Kampfspiel mit Karten: Beide wählen gleichzeitig geheim eine Aktion, dann läuft alles Frame für Frame ab. Mit **Flux** spulst du zurück, siehst die Karte des Gegners voraus – aber zu viel davon bringt Glitches, lügende Vorschauen und Halluzinationen. Prototyp: Ryo vs. Bront gegen KI. |
| 🃏 **Solitaire** | Klassisches Solitär (Klondike) im Retro-Fenster-Look. Doppelklick legt eine Karte automatisch ab. |
| 💾 **Retro 98 Desktop** | Nachgebauter Retro-Desktop mit Startmenü, Editor, Paint, Rechner, Eingabeaufforderung, Minesweeper, Solitär und Internet. |
| 📚 **Lernwerk** (`schule.html`) | Schulzentrale: Aufgaben, Noten-Schnitt, Stundenplan, Ferien-Countdown, Karteikarten, Formelsammlung, 3D-Labor und mehr. |
| 🎤 **Abgabegespräch-Training** | Übt das Abgabegespräch (BFS IT, Lernfeld 2). Eine KI spielt die Lehrkraft. Braucht einen eigenen **API-Key**. |
| 🎄 **Wichtel-Zentrale** (`wichtel.html`) | Getarnt als Weihnachts-Countdown. Dahinter: Spielhalle, Plätzchen-Bäckerei, Wichtel-Ziehung, Party-Tools, Chaos-Effekte, Kreativ- und Schul-Tools. |

### 🔑 Codes & Geheimnisse

<details>
<summary><b>🎄 Wichtel-Zentrale</b></summary>

- **Entsperren (Handy & PC):** 3× auf die große Tage-Zahl tippen, dann den Baum 🎄 **lang gedrückt halten**.
- **Entsperren (PC):** Einfach `wichteln` tippen.
- **Sofort tarnen:** `Esc` oder `Alt` + `T`. Die Seite tarnt sich auch automatisch, wenn der Tab gewechselt wird.
- **Lernplattform-Tarnung entsperren:** 3× auf die Prozentzahl bei „Fortschritt“ tippen, dann das 📘-Logo gedrückt halten (oder `wichteln` tippen).
- **Keks-Cheat:** In der Plätzchen-Bäckerei auf das 🍪-Symbol neben der Überschrift klicken.
</details>

<details>
<summary><b>💾 Retro 98 Desktop</b></summary>

- **Minesweeper:** `xyzzy` tippen, dann `Umschalt` + `Enter`. Danach beim Überfahren der Felder auf den obersten linken Bildpunkt des Bildschirms achten.
- **Solitär:** `Alt` + `Umschalt` + `2` gewinnt sofort.
- **Ausführen:** `absturz` (auf eigene Gefahr).
- **Eingabeaufforderung:** `matrix`, `format c:` (keine Angst).
- **Strg + Alt + Ende:** Den Task „Explorer“ beenden.
- Im Startmenü versteckt sich ein Uraltspiel.
</details>

<details>
<summary><b>⛏️ Klotzwelt – Befehle</b> (Chat mit <code>T</code>, Befehl mit <code>/</code>)</summary>

| Befehl | Wirkung |
|---|---|
| `/gamemode creative` · `/gamemode survival` | Spielmodus wechseln |
| `/give <item> [anzahl]` | Items geben |
| `/tp <x y z>` · `/tp spawn` · `/spawn` | Teleportieren |
| `/time set day/noon/sunset/night/midnight` | Uhrzeit ändern |
| `/weather clear/rain/thunder` | Wetter ändern |
| `/summon <mob> [anzahl]` | Monster/Tiere spawnen |
| `/setblock <x y z block>` · `/fill <x1 y1 z1 x2 y2 z2 block>` | Blöcke setzen/füllen |
| `/heal` · `/feed` · `/kill` · `/kill mobs` | Heilen, sättigen, töten |
| `/difficulty <0-2>` | Schwierigkeit |
| `/gamerule keepinventory true/false` · `/gamerule mobgriefing true/false` | Spielregeln |
| `/seed` · `/clear` · `/help` | Seed, Inventar leeren, Hilfe |

Tipp: Im Kreativmodus 2× `Leertaste` zum Fliegen, 2× `W` zum Sprinten.
</details>

<details>
<summary><b>🎵 Pulse Grid – Tasten</b></summary>

`Esc` Pause · `R` Neustart · `Leertaste` Intro überspringen

## 🇬🇧 English

> 🤖 This project was entirely **vibecoded**, meaning it was created with the help of AI – using both the **free** and the **paid** version of Claude (Anthropic).

✅ The code is **free to use**: you may use, modify and share it.

▶️ **How to play:** Every game is a single `.html` file. Just download it and open it in your browser.

### 📂 Games & pages

| File | Description |
|---|---|
| 🕹️ **ASCII Arcade** | Five retro games in ASCII style: **Doom, Pong, Tetris, Pacman** and **Nachtschicht** (night shift). Pick with the arrow keys, start with `Enter`. |
| ⛏️ **Klotzwelt** | Custom Minecraft-style voxel game with survival and creative mode, crafting, mobs and weather. Textures and sounds are generated live. |
| 🎵 **Pulse Grid** | Rhythm game: hit the notes on a 3×3 grid with your cursor. Load your own songs (auto-mapped) or import `.sspm`/`.txt` maps, plus lots of mods. |
| 💉 **Overdose Protocol** | Turn-based neon fighting game with cards: both players secretly pick an action at the same time, then it plays out frame by frame. Use **Flux** to rewind and peek at your opponent's card – but too much of it brings glitches, lying previews and hallucinations. Prototype: Ryo vs. Bront against the AI (German UI). |
| 🃏 **Solitaire** | Classic Klondike solitaire in a retro window. Double-click sends a card to the foundation. |
| 💾 **Retro 98 Desktop** | Recreated retro desktop with start menu, Notepad, Paint, calculator, command prompt, Minesweeper, Solitaire and "internet". |
| 📚 **Lernwerk** (`schule.html`) | School hub: tasks, grade average, timetable, holiday countdown, flashcards, formula collection, 3D lab and more (German). |
| 🎤 **Abgabegespräch-Training** | Practice for an oral exam; an AI plays the teacher. Requires your own **API key** (German). |
| 🎄 **Wichtel-Zentrale** (`wichtel.html`) | Disguised as a Christmas countdown. Behind it: arcade, cookie clicker, Secret Santa draw, party tools, chaos effects, creative and school tools. |

### 🔑 Codes & secrets

<details>
<summary><b>🎄 Wichtel-Zentrale</b></summary>

- **Unlock (phone & PC):** Tap the big day number 3×, then **press and hold** the tree 🎄.
- **Unlock (PC):** Just type `wichteln`.
- **Hide instantly:** `Esc` or `Alt` + `T`. It also hides itself when you switch tabs.
- **Unlock the learning-platform disguise:** Tap the "Fortschritt" percentage 3×, then hold the 📘 logo (or type `wichteln`).
- **Cookie cheat:** In the cookie bakery, click the 🍪 icon next to the heading.
</details>

<details>
<summary><b>💾 Retro 98 Desktop</b></summary>

- **Minesweeper:** Type `xyzzy`, then `Shift` + `Enter`. Then watch the top-left pixel of the screen while hovering over the fields.
- **Solitaire:** `Alt` + `Shift` + `2` wins instantly.
- **Run:** `absturz` (at your own risk).
- **Command prompt:** `matrix`, `format c:` (don't worry).
- **Ctrl + Alt + End:** End the "Explorer" task.
- An ancient game is hidden in the start menu.
</details>

<details>
<summary><b>⛏️ Klotzwelt – commands</b> (chat with <code>T</code>, command with <code>/</code>)</summary>

Same commands as in the German table above, e.g. `/gamemode creative`, `/give <item> [amount]`, `/tp spawn`, `/time set night`, `/weather thunder`, `/summon <mob>`, `/heal`, `/help`.

Tip: Double-tap `Space` in creative mode to fly, double-tap `W` to sprint.
</details>

<details>
<summary><b>🎵 Pulse Grid – keys</b></summary>

`Esc` pause · `R` retry · `Space` skip intro
</details>
